# Joscha Hillienhoff

**M.Sc. Business Information Systems (Data Science & AI), Paderborn University. I build ML and LLM systems end to end: from a messy problem and raw data to an evaluated model and a tool people use.**

## Featured projects

| Project | What it shows |
|---|---|
| [narrative-drift](https://github.com/joscha-hillienhoff/narrative-drift) | Streaming topic-shift detection on tech news: DenStream on sentence embeddings flags topic births, spikes and drift, LLM explanations checked against the source articles; 11 of 17 public events detected on 38,548 TechCrunch articles; PostgreSQL / pgvector, FastAPI and React |
| [deposit-forecasting](https://github.com/joscha-hillienhoff/deposit-forecasting) | Six forecasting models for household overnight deposits on public ECB data, rolling-origin backtest, SHAP explanations and rate scenarios; tested Python package with CI |
| [engineering-agents](https://github.com/joscha-hillienhoff/engineering-agents) | Small LangGraph multi-agent system: LLM agents query an RDF plant ontology with SPARQL, a SHACL validator rejects plans that break Ex-zone approvals and a human approves via interrupt; offline-tested |
| [ai-lions-den](https://github.com/joscha-hillienhoff/ai-lions-den) | Live pitch game: teams pitch to a jury of four LLM investors who question, score and decide; FastAPI and Next.js app, played live with a room of teams |
| [graph-llm-explainer](https://github.com/joscha-hillienhoff/graph-llm-explainer) | R-GCN on the AIFB knowledge graph (0.944 test accuracy), GNNExplainer edges turned into RDF facts that ground an LLM's conversational explanations |
| [news-recommender-system](https://github.com/joscha-hillienhoff/news-recommender-system) | Team project on Microsoft MIND: popularity, content-based, BPR and hybrid recommenders, compared on nDCG and CO2 cost |
| [dyad-sync-metrics](https://github.com/joscha-hillienhoff/dyad-sync-metrics) | Python library for two-person interaction data: movement synchrony and gaze measures, surrogate baselines and exact small-sample tests, tested on synthetic ground truth |
| [cnn_echo_aware](https://github.com/joscha-hillienhoff/cnn_echo_aware) | Echo-aware friend recommendation on Reddit reply networks: Siamese CNN and Node2Vec embeddings with FAISS retrieval; re-ranking raises diversity and cross-community exposure at about 20% recall cost |
